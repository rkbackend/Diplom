## Задание 1. Юнит-тесты

Нужно протестировать программу, которая помогает заказать бургер в **Stellar Burgers**.
Покрой программу юнит-тестами. Здесь пригодятся **моки** и **параметризация** — где именно их использовать, реши самостоятельно.

### Что нужно сделать

1. Склонировать репозиторий с заготовкой кода:
   `https://github.com/yandex-praktikum/qa-java-project`

2. Подключить библиотеки:

   * JaCoCo;
   * Mockito;
   * JUnit 4.

3. Покрыть тестами класс `Burger`.

4. Использовать:

   * моки;
   * стабы;
   * параметризацию там, где это необходимо.

5. Добиться покрытия кода **100%**.

### Как оформить результат

После клонирования репозитория с заготовкой кода нужно:

1. Доработать программу в IntelliJ IDEA.
2. Запушить ветку `develop1` на GitHub.

## Задание 2. Автотесты для API

Нужно протестировать эндпоинты API для **Stellar Burgers**.

Сервис:
`https://stellarburgers.education-services.ru/`

Документация API:
`https://code.s3.yandex.net/qa-automation-engineer/python-full/diploma/Api-Stellar_Burgers.pdf`

В документации описаны все эндпоинты сервиса.
Тестировать нужно только те, которые указаны в задании. Остальные можно использовать для контекста.

### Что нужно протестировать

#### Создание пользователя

Проверить:

1. Создание уникального пользователя.
2. Создание пользователя, который уже зарегистрирован.
3. Создание пользователя без одного из обязательных полей.

#### Логин пользователя

Проверить:

1. Вход под существующим пользователем.
2. Вход с неверным логином и паролем.

#### Создание заказа

Проверить:

1. Создание заказа с авторизацией.
2. Создание заказа без авторизации.
3. Создание заказа с ингредиентами.
4. Создание заказа без ингредиентов.
5. Создание заказа с неверным хешем ингредиентов.

### Что нужно сделать

1. Создать отдельный репозиторий для тестов API.

2. Создать Maven-проект.

3. Подключить библиотеки:

   * JUnit 4;
   * REST Assured;
   * Allure.

4. Написать тесты.

5. Сделать отчёт в Allure.

### Как оформить результат

1. Создать проект в IntelliJ IDEA.
2. Залить проект на GitHub.
3. Запушить ветку `develop2`.
4. Сделать pull request.

## Задание 3. Автотесты для UI

Нужно протестировать веб-приложение **Stellar Burgers**.

### Что нужно сделать

1. Описать элементы, которые будут использоваться в тестах, с помощью **Page Object**.

2. Протестировать функциональность в:

   * Google Chrome;
   * Яндекс Браузере.

3. Подключить Allure-отчёт.

### Что нужно протестировать

#### Регистрация

Проверить:

1. Успешную регистрацию.
2. Ошибку для некорректного пароля.

Минимальная длина пароля — **6 символов**.

#### Вход

Проверить:

1. Вход по кнопке **«Войти в аккаунт»** на главной странице.
2. Вход через кнопку **«Личный кабинет»**.
3. Вход через кнопку в форме регистрации.
4. Вход через кнопку в форме восстановления пароля.

#### Раздел «Конструктор»

Проверить, что работают переходы к разделам:

1. **Булки**.
2. **Соусы**.
3. **Начинки**.

### Как оформить результат

1. Написать код в IntelliJ IDEA.
2. Запушить ветку `develop3` на GitHub.
3. Сделать pull request.
